Steps to setup:
1. To run the project:
Clone project. If there are missing packages/vendor folder, use "go mod tidy" to install them.

2. To create new CRUD/module etc:
  i. Database
    a. Make new migration inside sql/schemas e.g sql/schemas/ (e.g sql/schemas e.g sql/schemas/001_users.sql) and define what goose up
       and goose down commands should do
    b. Open the terminal. Go to the sql/schema(or what you defined in sqlc.yaml file) folder and use 
       "goose postgres://postgres:@localhost:5432/golang_web_server up" to run all migrations.
       ** Worth mentioning that "goose postgres://postgres:@localhost:5432/golang_web_server down" rolls back one migration(sql) file at a time
    c. Create sql file inside sql/queries(e.g sql/queries/users.sql), follow sqlc formatting and define queries(so it can generate corresponding 
       repository fns properly) for the CRUD and other functionalities. Go back to root folder and run "sqlc generate" to generate said
       functions(will be stored in internal/db or per what you defined in sqlc.yaml)
  ii. Module(for current abstraction)
    a. Add new folder inside modules folder named {your_module_name}
    b. Make new handler.go, services.go, repository.go, structs.go and errors.go file inside {your_module_name} folder. Remember that 
       they must have the same package name(i.e unique name per folder).
    c. Copy handler template(Handler struct and New method) from other modules and write your logic. Each handler method must return error or nil.
       They must also have a response writer(for returning JSON responses) and a return nil at the very end.
       In order to write your logic here:
         * Create/write any structs + validations that you need inside {your_module_name}/structs.go
         * Create any errors that you wanna throw inside {your_module_name}/errors.go
         * Create(copy template for ease) any services you want to call from the handler inside services.go
         * Create(copy template for ease) any repositories you want to call from the services inside repository.go
    e. Bind the new handler (i.e {your_module_name}/handler.go) to your internal/server/server.go file
    f. Use the new handler to create new routes, but remember to wrap them in server.Handle(...) so you can log all errors in the
       global error logger
